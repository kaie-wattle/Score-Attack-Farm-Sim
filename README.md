# 農業経営シミュレーションゲーム

## 概要
プレイヤーは農地と畜産の両方を経営し、限られた期間内で収益を最大化することを目指す農業経営シミュレーションゲームです。耕作・畜産・収支管理の3つの仕組みを組み合わせ、戦略的な経営判断が求められる設計を目指しています。

## プレイ方法
右上のReleasesからzipをダウンロードして解凍後、exeを実行してください。

### 操作説明
- 耕作・畜産の切り替えはマップ上のボタンで行います
- ショップで種子・家畜・拡張を購入できます
- ターンを進めるには「次の月へ」ボタンを押してください
- 詳しい操作はゲーム内のチュートリアルをご確認ください

## 使用技術
- Unity 6
- C#
- ScriptableObject
- TileMap

## 技術的ポイント

### データ駆動設計
家畜・作物・ショップ商品・スコアボーナスをScriptableObjectで管理しています。新しい種類を追加する際にコードを修正せず、Assetを追加するだけで対応できる拡張性を持たせています。

### スコアボーナスの拡張設計
スコアボーナスはScriptableObjectと抽象クラスを組み合わせた設計にしており、新しいボーナス条件を追加する際にScoreManager本体を修正せず、新しいクラスを追加するだけで対応できる構造にしています。

### 耕作・畜産システム
耕作システムでは種子選択から自動収穫までを一連の処理として実装し、畜産システムでは土地の空き状況を判定した上での自動配置処理を実装しています。家畜は「時間経過で売却されるタイプ」と「継続的に収入を生むタイプ」の2種を持たせ、共通のインターフェースで管理することでコードの重複を避けつつ拡張性を持たせています。

### Manager構成
役割分離を意識したManager構成にしており、GameManager・UIManager・ShopManager・ResourceManagerなど各Managerが単一の責務を持つ設計にしています。

## 工夫・課題
畜産システムにおいて「売却型」と「継続収入型」という異なる収益構造を同じ仕組みの中で管理する点に難しさがありました。共通のインターフェースを設け、家畜の種類ごとに収益発生のロジックだけを切り替えられる構造にすることで解決しました。また自動収穫・自動配置など「自動化による快適なプレイ感」と「プレイヤーが戦略を考える余地」のバランスをどう取るかも工夫した点です。
